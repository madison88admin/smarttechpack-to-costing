A costing-approval workflow platform for Madison88 (apparel). PBD pulls a style + BOM from the NextGen ERP, sends it to the factory for a Cost Breakdown (CBD), and the costing goes through MD technical review → Costing validation → PBD approval, with full audit, benchmarks, and customer-status tracking after that. Next.js 14 + React 18 + TypeScript, ~80 lib modules, ~90 API routes, 81 test files (784 tests), 15 migrations.
